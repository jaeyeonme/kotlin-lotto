# kotlin-lotto

## Step 2 로또 자동

### 로또 번호와 티켓

- [x] 로또 번호는 1부터 45까지의 값만 허용한다.
- [x] 로또 티켓은 서로 다른 번호 6개를 오름차순으로 관리한다.
- [x] 지난주 당첨 번호는 서로 다른 번호 6개로 관리한다.

### 자동 구매

- [x] 로또 한 장의 가격은 1,000원이다.
- [x] 구입 금액만큼 로또를 자동 발급한다.
- [x] 자동 생성된 로또 번호는 테스트에서 제어할 수 있다.

### 당첨 통계

- [x] 당첨 번호와 3개부터 6개까지 일치한 티켓 수를 집계한다.
- [x] 일치 개수에 따라 당첨 금액을 계산한다.
- [x] 총 당첨금을 구입 금액으로 나눈 수익률을 계산한다.

### 콘솔 입출력

- [x] 구입 금액과 지난주 당첨 번호를 입력받는다.
- [x] 구입한 로또 수와 각 티켓의 번호를 출력한다.
- [x] 등수별 당첨 통계와 총 수익률을 출력한다.

## Step 3 로또 2등

### 보너스 번호

- [x] 지난주 당첨 번호 다음에 보너스 번호를 입력받는다.
- [x] 보너스 번호는 1부터 45 사이의 값만 허용한다.
- [x] 보너스 번호는 지난주 당첨 번호와 중복될 수 없다.

### 2등 당첨 판정

- [x] 당첨 번호 5개와 보너스 번호가 일치하면 2등으로 판정한다.
- [x] 당첨 번호 5개만 일치하면 3등으로 판정한다.
- [x] 보너스 번호 포함 여부와 등수 판정은 로또 티켓 밖에서 수행한다.

### 당첨 통계

- [x] 2등 당첨금 30,000,000원을 총 당첨금에 포함한다.
- [x] 2등 티켓 수가 0개인 경우를 포함해 당첨 통계에 출력한다.
- [x] 2등 당첨금을 반영한 수익률을 계산한다.
